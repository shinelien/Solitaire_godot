## ADR-001：SOL 4.5.1 阶段映射

- 日期：2026-09-02
- 决策：建立唯一有效阶段 `S1-GODOT-CORE-LOOP`。
- 理由：负责人给出一个连续授权目标——复刻旧版核心玩法并形成 Godot 可玩闭环。该目标可独立表述、可整体观察验收、可在不隐藏同一授权内未完成内容的前提下关闭，并命中 SOL 4.5.1 第 4.2.4.1。
- 迁移：交接中的 CORE-001、CORE-002、CORE-003、CORE-004、CORE-005、CORE-006、CORE-007、UI-001 全部是同一阶段内部工作包。不按章节、模块、文件或测试批次建立伪阶段。
- 影响：执行者必须连续施工至整个闭环到达终止交接状态；工作包完成不触发裁决。

## ADR-003：Core 边界和状态流

- 日期：2026-09-02
- 决策：采用纯 typed GDScript Core，`GameState` 是 SSOT，所有行为以 `Move` 表达并由 `MoveExecutor` 原子执行，Presentation 单向渲染。
- 关键语义：自动暴露的 Tableau 翻牌是同一用户命令事务内的显式 `FlipTableau` Move；Undo 以事务前深拷贝 snapshot 恢复；Replay 恢复原始牌局与 Draw 模式。
- 理由：这使玩家、Hint、Auto Complete 和未来 Solver 共享一套可测试语义，并为 Assist 的可观测事务预留边界。

## ADR-004：旧牌局兼容语义

- 日期：2026-09-02
- 决策：每条存储记录是 52 个 ASCII 字节 + 1 个换行；Card ID = `byte - 0x30`；rank = `id % 13 + 1`，suit = `id / 13`。
- 发牌：先反转 52 字节得到 draw order，再以 column 0→6 为外循环，分别取 1…7 张填 Tableau，各列最后一张 face-up；剩余 24 张依次进 Stock。
- 错误语义：指定旧牌局的解码失败必须明确失败，禁止返回随机牌并伪装兼容成功。

## ADR-006：施工发布权与 Godot AI MCP 强制通道

- 日期：2026-09-02
- 负责人决定：Sol 只设计架构、施工合同、风险与验收，不代替负责人指挥或启动施工执行者。施工任务由负责人亲自发布。
- 执行通道：执行者必须通过项目内已安装的 Godot AI MCP 与实时 Godot 编辑器协作。必须使用的能力类别包括 editor state/logs/screenshot、scene/node/ui/script/project/filesystem 管理、test run、project/game run 和交互验证。
- 禁止降级：文件系统可用于只读 Cocos 取证、大型静态牌库复制和必要的批量文本编辑，但每批 Godot 变更都必须通过 MCP 扫描/重载、诊断并验证。仅用头部 CLI 测试不构成合同履行。
- 不可用时：如 Godot AI MCP 未连接、必要工具被禁用或编辑器不可操作，执行者必须提交最小阻塞请求，不得绕过。
- 纠正记录：Sol 曾在负责人明确本边界前误启动一次执行者，已立即终止。检查确认无代码、场景、项目配置或 Cocos 工作树改动；退出前生成的两个牌库副本和 `.DS_Store` 已移到可恢复隔离目录 `/Users/lian/.Trash/codex-aborted-solitaire-worker-20260902-0304/`，施工目录已恢复为仅新增 SOL 文档。

## ADR-007：合同 2.0 的 Cocos 美术与旧版分辨率基线

- 日期：2026-09-02
- 负责人决定：核心闭环直接复用固定 Cocos 版本的牌面、牌背、牌桌背景/槽位和核心操作按钮；Godot 采用与旧版相同的设计分辨率和宽度固定适配。
- 一手依据：`Classes/AppDelegate.cpp` 明确 `1080×1920` 与 `ResolutionPolicy::FIXED_WIDTH`；`GameLayerHD.csd` 根尺寸同为 1080×1920，牌位 146×220；`AppConstant.h` 的运行时牌尺寸为 148×220。
- Godot 映射：`viewport 1080×1920 + canvas_items + keep_width + portrait`。这是 Godot 官方机制中与 FIXED_WIDTH 最接近的等价语义，仍需以 9:16 和高屏实际截图/输入验证。
- 资产策略：只从固定 Git 对象复制核心闭环所需原始 blob；Cocos/Spine atlas 可确定性转换为 Godot AtlasTexture/region 或无损裁切 PNG，但不得重绘或引入 Cocos/Spine runtime。
- 阶段影响：该要求属于现有 `S1-GODOT-CORE-LOOP` 的可观察整体结果，不新增 UI 伪阶段。
- 验收影响：上一轮执行者候选尚未被技术总监裁决，且使用 1280×800 临时横屏/程序绘制牌面，因此该候选失效并转历史；合同升级为 SOL 4.5.2 / 执行合同 3.2，由负责人重新发布后方可复工。
