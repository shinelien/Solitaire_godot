## 当前目标与基准

使用 Godot 原生节点、资源和动画完整复刻 Cocos **InvincibleWarrior**，包含大厅、经典纸牌、关卡、每日挑战、鱼缸养成、Spine 翻牌、交互和场景动画。广告 SDK 暂不接入，保留服务接口。

用户最终确认版本：本地保存的 `origin/InvincibleWarrior`，提交 `12b33cbed`，2021-11-30。参考源码提取在 `reference/InvincibleWarrior/`。Cocos 原工作区仍为 master `515710ad2`，没有切换或修改原版代码。

此前根据 2018 master 制作的 `master_main.tscn` 已停止扩展，保留为草稿。其截图和测试不能作为当前目标的验收依据。

**状态：进行中，尚未完成完整复刻。**

## 1080 制作规格与工程入口

- 设计尺寸：**1080×1920 竖屏**，与原版 AppDelegate 一致。
- 场景、纸牌、动画和输入统一使用 1080 设计坐标；Godot 使用 `canvas_items`／`keep_width`。
- 桌面预览窗口：540×960。验证脚本另用 1080×1920 SubViewport 获取真实分辨率的渲染图片，并检查图片像素尺寸。
- 工程：`S1/project.godot`；当前主场景：`S1/scenes/invincible_main.tscn`。
- 产品实现：`S1/solitaire/invincible/`；原有纯规则引擎：`S1/solitaire/core/`、`application/`、`deal/`。
- 新版资源：`S1/assets/invincible/`；Godot 原生场景：`S1/scenes/invincible/`。
- 运行验证图片：`S1/docs/invincible-evidence/`，当前图片为 1080×1920。
- 广告预留：`S1/solitaire/native/ad_service.gd`，无 SDK；奖励须经服务回执确认。

## 当前实现

| 内容 | 实现与边界 |
| --- | --- |
| 原版资源与场景迁移 | 转换 240 个 CSD、8125 个节点、541 个命名动画片段为 Godot 场景与 AnimationPlayer。资源导入不等于全部产品流程已接通。 |
| Spine 纸牌与鱼 | 使用原仓库 Spine C evaluator 离线采样权重网格及约束，Godot Polygon2D / AnimationPlayer 播放纸牌和 25 类鱼的动画；翻牌使用原始 flop / unflop 事件。保留原 Runtime 许可头。还需逐帧核对材质混合和动画效果。 |
| 粒子 | 转换 40 个 plist 为 CPUParticles2D，解压并转换内嵌贴图；3 个径向发射器尚未准确实现，其他粒子分布也需视觉校准。 |
| 牌桌 | 52 张持续存在的牌节点；点击、拖动、撤销、提示、自动收牌、翻一／三张；左手模式同时调整牌和原版牌位。移牌和翻牌分别由 Godot Tween 与 AnimationPlayer 执行。 |
| 新版计分 | 移牌、翻开、撤销采用 InvincibleWarrior 的计分；循环牌堆不继承旧 master 的扣分规则。限时关卡按原版 times×2.5 向下取整到十秒。 |
| 大厅与鱼缸 | 大厅切换，4 套原版背景时间轴，初始鱼游动、喂食、饥饿数据和本地保存；鱼的路线与行为目前是基础实现。 |
| 鱼商店／鱼缸选择 | 原版商店场景、25 类鱼价格与等级条件、金币购买；鱼缸按 0／18／39／60 级解锁。售卖、装饰升级等仍未完成。 |
| 关卡 | 接通 6 个开放分组、300 关配置；按各组真实数量显示列表和前一关完成条件。胜利展示及奖励流程仍需完整迁移。 |
| 每日挑战 | 原版日历、日期选择、月份切换、4 种模式及源牌库接通；共 366 行数据。保留普通日期的原版索引，闰年最后一天使用原来未用的第 0 行，避免原代码越界。每日奖励流程仍未完成。 |
| 玩家数据与声音 | 独立 InvincibleWarrior 存档，等级经验、金币、设置；基础按钮、移牌、翻牌和撤销音效。原版 playMusic() 已禁用背景音乐，当前遵循该行为。 |

## 当前验证

使用本机 Godot 4.6.2 custom build / GL Compatibility。

- 规则及产品数据测试：**208 项通过，0 失败，共 19 套件**。新套件覆盖新版发牌与循环计分、限时公式、全部每日牌库有效性、翻牌事件和动态纹理方向。旧 master 草稿的 5 项测试仍独立存在，不能证明新版完整性。
- 240 个转换场景完成加载和实例化检查；场景运行过程中修正了内嵌 TIFF 贴图格式、失败的纹理导入记录、粒子资源序列化及纹理大小写冲突。
- 图形运行脚本验证 1080×1920 像素输出、52 张牌、真实 Viewport 鼠标输入抽牌、左手抽三张；大厅、暂停、商店、鱼缸、关卡、每日场景由控制器调用打开并截图。
- 当前截图包含普通牌桌、抽牌、暂停、大厅、鱼商店、鱼缸列表、关卡分组／列表、每日日期／模式／牌桌及左手翻三张。控制器调用截图不代表所有按钮已由鼠标实际点击验收。
- 测试和验证脚本退出时仍有 RID／资源泄漏告警，需要后续定位；不能称为无告警运行。
- 没有完成原 Cocos 运行画面与 Godot 的逐帧并排比较，也未完成手机设备或导出包验收。

7. 退出资源告警定位、生产导出资源包含规则（尤其 `.json.gz` 和 `.d`）、真机性能与完整用户流程验收。
