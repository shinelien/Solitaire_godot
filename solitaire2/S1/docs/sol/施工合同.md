## 3. 方案依据、固定事实与架构决定

### 3.1 官方 Godot 依据（stable）

- RefCounted：自动引用计数的值语义对象基类（Resource 与其继承者）。
  - https://docs.godotengine.org/en/stable/classes/class_refcounted.html
- Control：全部 GUI/UI 的基类，基于锚点/偏移自适应父级与屏幕尺寸，UI 输入走 `_gui_input`。
  - https://docs.godotengine.org/en/stable/classes/class_control.html
- TextureRect：显示一张 texture 的 Control；配合 AtlasTexture 的 region 可直接切图。
  - https://docs.godotengine.org/en/stable/classes/class_texturerect.html
- 静态类型 GDScript：变量/参数/返回/容器元素可静态类型化；**嵌套类型数组不受支持（`Array[Array[int]]` 被禁止）**——因此 tableau/foundation 用 `Array[CardPile]`。
  - https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/static_typing.html
- 多分辨率：base size = 设计尺寸；`canvas_items` 拉伸；**Keep Width = 固定设计宽度、纵向扩展**，最适合锚定式 GUI/HUD；竖屏建议 base 1080×1920、`canvas_items`。
  - https://docs.godotengine.org/en/stable/tutorials/rendering/multiple_resolutions.html

  - `Resources/data/bureau1.d` `c43a895…`（32084 条记录 × 53 字节=52 字符+LF；总字节 1700452）；`Resources/data/bureau3.d` `a04650d…`（4999 条）。
  - `Resources/game/car_new_0_1.png/.atlas`、`car_new_0_6.png/.atlas`（Spine 文本 atlas：size 1858×1776 RGBA8888，108 个 region 如 `card_0_1A`/`card_0_A11`，每 region 148×220）。
  - `Resources/background-0.png` `c47b1a64…`；`Resources/music/{deal,shuffle,movecard,nomove,undo,autoplay,auto,victory}.mp3`。
- 旧解码（SpriteManager `initCardIds`，74f51802… 实测）：bureau 记录 52 个符号（ASCII 48..99，即 `id = 符号字节 − 48` ∈ [0,51]），循环 `*(it+51-i)-'0'`（i=0..51）把整条记录**逆序**填入 `cardIds`（即 `cardIds = reverse(record)`，SpriteManager.cpp:260-263）；发牌 `getCardId()` 对 `cardIds` **前端 FIFO** 取牌（SpriteManager.cpp:505、534-536），**实际出牌顺序 = `reverse(record)`（仅一次反转）**。`currentBureau` 另行由 `cardIds` 顺序转串后整条反转（SpriteManager.cpp:311-316）恢复**原记录正向序**，**仅用于日志/序列化上报**（GameViewHD.cpp:1542/2393/3075 `"bu"` 字段）；该反转不改动 `cardIds`，不是发牌顺序来源。
- 旧牌局事实（TD 预调查裁定口径）：设计 1080×1920、`ResolutionPolicy::FIXED_WIDTH`（`Classes/AppDelegate.cpp`：56、114 行）；牌垫 pad 1080×1440；牌 `POKER_SIZE 148×220`（AppConstant.h:105）；盖牌/翻牌堆叠偏移 `OffsetNoOpen=30`/`OffsetOpen=66`（AppConstant.h:113-114；CardSprite.cpp:1024 注释）；bureau1=32084、bureau3=4999 条记录，每条 52 字符 + LF；id=字符−48；整条反转；FIFO 消费；tableau 列主序 1..7；剩余 24 张由 stock 自底向上存放、顶端在数组末尾；旧“玩家就绪态”在发牌后自动翻 1 或翻 3。
- 牌面 = atlas region，无需 Spine 运行时也无需烘焙 52 张新图。

### 3.3 架构决定（§ 记录于 `决策记录.md` ADR-007..010）

1. 固定旧源（ADR-007）：产品参考锁定 `74f51802…`，禁止 checkout/写入；所有资产/数据只从该对象的 Git blob 确定性导出（路径+blob+SHA-256）。
2. 纯核心/状态/移动架构（ADR-008）：分层 **Presentation → Application → Core**；发牌供给 Application/Core 但不得依赖 Presentation；Core 不含 Node/Control/Texture/Firebase/广告/SEO/服务器；**Scene Tree 不是 GameState**。
3. 2D atlas/布局策略（ADR-009）：legacy atlas 解析隔离在呈现基础设施；CardView 用 Control/TextureRect 组合原 `car_new_0_6`/`card-back` atlas 的 AtlasTexture region；不移植 Spine、不烘焙 52 张新图；Core 永不知道纹理/atlas。
4. 显式排除（ADR-010）：见 §13。

## 4. 数据与移动架构（WP-05/WP-06 落地）

1. `CardData`、`CardPile` 为 `RefCounted` 纯数据；`rank = id%13+1`、`suit = id/13`。
2. `GameState` 是**唯一事实来源**且**可深拷贝**；存储 stock/waste/tableau[7]/foundation[4]、draw_count、stock_passes、move_count、score、status、deal identity；tableau/foundation 用 `Array[CardPile]`（规避不支持的嵌套类型数组）。
3. 所有会改变进行中状态的操作（玩家输入、Hint、AutoComplete、replay）一律经 **Move/MoveBatch + RulesEngine + MoveExecutor**：执行器返回**新状态**与显式的 applied/generated moves，源状态不被修改；翻开 tableaus 暴露张是显式生成移动 `FlipTableau`；非法移动返回类型化结果且不得改状态。
4. 撤销：按**用户动作**（MoveBatch）建快照历史，容量下限 ≥100；恢复精确状态后按需应用显式的 legacy 撤销计分策略；不做位置重建。
5. 视图只渲染 GameState，从不直接改它（WP-08）。

## 5. 发牌、规则与确定性（WP-05..WP-07 落地）

1. **两种快照**要区分：发牌快照（28 tableau + 24 stock，waste 空）与**玩家就绪快照**（发牌后自动 DrawStock 1 或 3 后的状态）；stock 约定自底向上、顶端在数组末尾。
2. 确定性解码器拒绝长度/字符/重复/缺失错误，**不允许回退随机化**。
3. 经典规则：foundation 同花升序、仅空位放 A；tableau 降序红黑交替、仅空位放 K；可移动已翻开的有序 run；stock 翻 1/3 并可 recycle；源张/可达性规则；tableau 暴露后自动翻牌；4 个满 foundation = 获胜。仅当显式且有测试时才保留基础计分行为，且不得污染合法性。
4. `HintEngine`：确定性合法移动选择，不改状态。`AutoCompletePlanner`：仅当全部 tableau 牌已翻开后激活，只发普通合法移动（按需含 stock 翻牌/回收），不得换牌/改牌身份。`Replay` 精确复原原发牌；`New Deal` 选不同确定性仓库索引。无隐藏辅助。
5. Golden 范围：≥100 条 bureau1 用例 + 代表性 bureau3；fixtures 存原始 deal 与预期 dealt tableau/stock 及 ready 翻 1/翻 3 快照；产品解码器必须对照预计算 fixtures 测试。**固定记录 0** 的预期消费/tableau/stock 与规范 hash `935879b0483480ea8f936cdc2c2b236d532d2b9531f800b19173f8dd50d620e3`。TD 独立抽检 fixtures。
